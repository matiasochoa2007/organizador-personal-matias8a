# Recomendaciones de mejora

1. **Agregar pruebas automatizadas**  
   Incluir un conjunto básico de pruebas unitarias en la carpeta `tests/` para validar las funciones principales del proyecto. Esto ayudará a detectar errores rápidamente y garantizar la calidad del código.

2. **Documentación más detallada**  
   Ampliar el archivo `docs/descripcion.md` con un diagrama de flujo que muestre cómo se gestionan las tareas y notas dentro de la aplicación. Esto facilitará la comprensión del proyecto a nuevos colaboradores.

3. **Configuración de CI/CD**  
   Integrar el repositorio con GitHub Actions para automatizar la ejecución de pruebas y la verificación de dependencias cada vez que se haga un commit o Pull Request. Esto asegura que el proyecto se mantenga estable y actualizado.
